- Add Windows release documentation, checksum distribution, least-privilege pinned CI
  and isolated archive/install/shim verification. Retain the owner-selected MIT license.

Linux source is unverified; macOS safe file output is unfinished. The native matrix,
Ubuntu reference performance, cross-platform package/engine/CI and npm readiness
remain mandatory outstanding work. This is not a production-ready stable release.
